# scikit-ops

Image-processing ops you can call directly, run in their own environment, or
use from napari and Fiji.

This is a development release. It does not work from PyPI yet, because the
packages it depends on are still in development. Early adopters can install
it from GitHub:

```sh
pip install git+https://github.com/apposed/scikit-ops
```

- Source: https://github.com/apposed/scikit-ops
- Docs: https://scikit-ops.readthedocs.io
